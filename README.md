WK2-PM1: Footprinting with Multiple Kali Linux Tools

Project Overview

This project demonstrates passive footprinting and information gathering using Kali Linux tools.

Target Company

* Company: Cloudflare, Inc.
* Domain: cloudflare.com
* Website: https://www.cloudflare.com/

Tools Used

1. WHOIS – Retrieves domain registration information.
2. WhatWeb – Identifies web technologies used by a website.
3. NSLookup – Retrieves DNS records.
4. DNSRecon – Collects DNS information.
5. WAFW00F – Checks for Web Application Firewall indicators.
6. cURL – Retrieves HTTP response headers and website information.

Evidence Files

File	Description
whois.txt	WHOIS results
whatweb.txt	Website technology information
nslookup.txt	DNS lookup results
dnsrecon.txt	DNS reconnaissance results
wafw00f.txt	WAF detection results
curl.txt	HTTP request results

Objective

To understand how different Kali Linux tools can be used for footprinting and reconnaissance.

Disclaimer

This project is for educational purposes. Testing is limited to passive information gathering and authorized activities.
